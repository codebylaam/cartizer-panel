# Taste
- Expects SPA behavior from React apps: link clicks should navigate client-side, and any full page reload triggered by in-app links is treated as a bug to be fixed (often globally, via a link component/provider) rather than worked around. Confidence: 0.65
- Wants new pages/features implemented to match the pattern of an already-done sibling page ("do X also"), so the codebase stays consistent rather than each screen inventing its own approach. Confidence: 0.55
- Prefers building UI with the Astryx design system components — explicitly asks for the "astryx table" rather than hand-rolled markup or TanStack Table column defs — including Astryx's own plugin pipeline (`useTablePagination`, `useTableSortable`), and names the specific component to use when a piece of UI is being reworked (e.g. "implement ComplexSelector"). Confidence: 0.6
- Expects no custom styling to be introduced: the project has no StyleX compiler, so richer UI should be achieved by composing stock Astryx components (accepting a less compact layout) rather than adding xstyle/utility classes or bespoke CSS. Confidence: 0.55
- Expects screens implemented "properly", i.e. end-to-end wiring rather than stubs: filter/pagination/sort state driven through URL search params, forwarded into the API request params and the query key, with pending/error/empty states handled. Confidence: 0.55
- All user-facing copy goes through i18n `t()` keys, added to every maintained locale (en and bn) in parallel. Confidence: 0.5
- Follows the project's AGENTS.md design-system rules: status is rendered with StatusDot/Token, Badge is reserved for counts. Confidence: 0.55
- Expects the project's API convention of `/{singular-resource}/{action}` paths (e.g. `/product/list`, `/product/create`, `/product/update`, `/order/list`, `/order/create`) instead of RESTful plural paths like `/api/products` — and actively corrects endpoints that deviate from it. Confidence: 0.6
- Prefers consolidated controls over one-control-per-field: when several related values are edited together, wants a single selector/popup that shows all of them at once with an explicit Apply button (staged draft commit) instead of inline per-field controls that commit immediately. Confidence: 0.45
- Gives terse, high-level instructions, often just pointing at a single target file/route with an @-mention (e.g. "Implement @src/routes/_authenticated/inventory/index.tsx page", "Implement @src/routes/_authenticated/medias/index.tsx page", "fix the create order page"), and expects the agent to diagnose root causes and implement/repair the whole feature end-to-end (including adjacent broken/dead code) without step-by-step hand-holding. Confidence: 0.65
